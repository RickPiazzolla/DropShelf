# DropShelf

A drag-and-drop staging shelf for Windows.

Windows makes you finish a drag in one motion. If you pick up a file in one window
and the destination is not already visible, you are stuck: you cannot switch apps,
scroll, or change virtual desktop without dropping what you are holding.

DropShelf gives you somewhere to put it down. Drop files onto the shelf, go and find
the destination at your own pace, then drag them back off.

macOS has had Dropover and Yoink for years. Windows has not had a good equivalent.

## Status

Early development. See [ROADMAP.md](ROADMAP.md) for what is built and what is planned.

- Windows 10 version 1809 or later
- .NET 9 Desktop Runtime
